FlowGuard AI — Traffic Incident Monitoring

Project Overview:

FlowGuard AI is a traffic monitoring dashboard designed to analyze traffic videos, detect vehicles, and display traffic incidents for easier monitoring.

Features:

- Traffic video upload and analysis
- Vehicle detection using YOLOv8
- Traffic incident monitoring
- Interactive map using Leaflet and OpenStreetMap
- Dashboard for displaying incident information

Technologies Used:

- Frontend: React, JavaScript, HTML, CSS
- Backend: Python, FastAPI
- AI: YOLOv8, Ultralytics
- Map: Leaflet, OpenStreetMap

Project Structure:

- "frontend/" — User interface and map
- "backend/" — API and detection logic

Requirements:

- Python
- Node.js and npm
- Internet connection for map tiles and downloading the model when required


- Improve incident mapping and reporting
